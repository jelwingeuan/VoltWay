- Local Supabase setup is under-specified: `README.md:11-16` recommends `Config/Secrets.xcconfig`, but `VoltWay.xcodeproj/project.pbxproj:77-78` does not attach it. Low-effort documentation or optional-include work is useful after the reliability fixes.
- The private-site RPC accepts a JSON object/connector array that the station normalizer later rejects (`supabase/migrations/202609280003_private_charger_sharing.sql:4-9,79-92`; `supabase/functions/stations/shared.ts:166-185`). Add server-side validation and direct-RPC tests before a live owner-sharing pilot.
- `VoltWay.xcodeproj/project.pbxproj:52-57` has no UI-test target for Explore's map/sheet interactions. Add a small demo-fixture XCUITest flow after 001 establishes a working simulator gate.
- `supabase/functions/stations/index.ts:30-35,95-113` rereads full daily public catalogs on every request. Measure transfer/parse cost with a realistic approved snapshot before choosing a cache; cache only public data, never user-specific private sites or live partner status.
- `VoltWay/Views.swift` is a 2,505-line high-churn screen module. Split at complete screen boundaries only after interaction coverage exists; a mechanical split now has lower leverage than the correctness/privacy items.

## Direction options (not defects)

- **Catalog health**: the scheduled imports in `supabase/schedule_open_charge_map.sql` and `supabase/schedule_mevnet.sql` retain the prior snapshot on failure, while Coverage mainly shows the last sync (`VoltWay/Views.swift:558-565`). Define source-specific freshness expectations and an operator alert before scaling the nationwide prototype. This is a design/spike, not a blanket “live” claim.
- **Connector-level trust**: plan 003 conservatively avoids an unsafe merged status. A future partner contract and data model could represent connector provenance/status separately, restoring directory-only connector discoverability at deduplicated sites without misleading availability. This touches backend, iPhone, and CarPlay, so it should follow a written data contract.
